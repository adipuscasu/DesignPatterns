## Gamma Catogorization

* Design Patterns are divided into three categories:
  * Creational
  * Structural
  * Behavioral
* This is called Gamma Catogorization because the authors of the book `Design Patterns: Elements of Reusable Object-Oriented Software` are Erich Gamma, Richard Helm, Ralph Johnson, and John Vlissides. They are also known as Gang of Four (GoF).
* The book was published in 1994 and is considered as the bible of design patterns.
* The book has 23 design patterns.

  ### Creational Design Patterns
* Deal with the creation (construction) of objects.
* Explicit (constructor) vs. implicit (DI, reflection, etc.).
* Wholesale (single statement) vs. piecewise (step-by-step).

    ### Structural Design Patterns
* Concerned with the structure (e.g., class members).
* Many patterns are wrappers that mimic the underlying class interface.
* Stress the importance of good API design.
    ### Behavioral Design Patterns
* They are all different; no central theme.
